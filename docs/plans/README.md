## 维护规则

- `docs/plans/`：存在未完成交付、真实数据、生产切换、外部验收或明确后续批次。

- “代码已完成但生产未验收”仍属于活跃计划，不能仅因本地测试通过而归档。
- 归档时必须同步修正 `docs/INDEX.md` 和活跃计划中的引用，不复制第二份文档。
