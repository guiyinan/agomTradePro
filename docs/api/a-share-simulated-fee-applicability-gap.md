# 普通模拟费用适用范围：消费者切换前阻断项

实现进展：已增加[精确 case 的费用 V2 合同与管理入口](a-share-simulated-fee-policy-v2.md)，当前正在完成最终独立联验。下述旧公式问题仍用于解释历史 V1；旧消费者尚未切换，不把新合同等同于真实市场费率已配置或整条链路已验收。

ASH-02 的结算 UoW 先验证精确数值、现金/持仓原子性、T+1 及重放。当前费用候选读取既有 FeeConfig 的 FloatField，并以 `Decimal.from_float` 保留实际数据库 binary64 值，标记 `NORMAL_SIM_ESTIMATED / DATABASE_BINARY64`；这不证明最初录入的十进制原值，也不是券商实际成交费用。

独立审查发现候选费用公式复制了旧逻辑：仅当 `market == "SH"` 且配置资产为 `equity` 时计算过户费。既有 FeeConfig 只有费率，没有可核验的市场和方向适用范围。把 `SZ`、`BJ`、原始交易所代码 `SSE` 或其他未知值落入零费用分支，不能作为现行 A 股费制的实现。

中国结算公布的[上海市场收费表](https://www.chinaclear.cn/zdjs/fbzyls/202506/9d22b74d9f2e40edb67b44d1f6596f18/files/上海市场证券登记结算业务收费及代收税费一览表.pdf)、[深圳市场收费表](https://www.chinaclear.cn/zdjs/fbzyls/202506/ab6384ba25514554a7eceaee3e521032/files/深圳市场证券登记结算业务收费及代收税费一览表.pdf)和[北京市场收费表](https://www.chinaclear.cn/zdjs/fbzyls/202506/69144099e23c436ab678b9d778260402/files/北京市场证券登记结算业务收费及代收税费一览表.pdf)均列有 A 股交易/股份过户费。上述 2025 年公布资料足以反驳“仅上海”的旧假设，不作为自动初始化 2026 年账户费用的授权。具体证券、业务、券商收费及适用日期还须按当时有效文件和账户约定核实。

## 下一有界切片

复用 FeeConfig，先设计显式、可管理、可版本化的市场/资产/买卖方向适用范围；缺少声明、超出声明或声明歧义时发布费用配置不可用，不能推定零。新字段对历史配置保持空值，不自动给历史记录补市场或改费率。管理/初始化入口必须明确输入这些值及依据，不能在 Domain、Application、shared 或启动代码硬编码业务默认。

精确费用快照和内容 hash 必须同时绑定数值、适用范围、版本、计算目的及舍入口径。费率来自既有实际存储值；适用性来自明确配置。规范化市场身份与来源交易所身份的转换还需真实 owner 合同，不从代码前缀推导。分项到分舍入与先汇总再舍入可能不同，必须明确版本、保存差异样例，不能声称与旧 float 运算完全兼容。

只有该切片与正式日历、规则和普通模拟消费者联合通过后，才切换旧买卖及自动模拟入口。实际成交导入保留已知实收分项；未知费用仍为未知，不经过预估费用路径，不重复扣款。当前 `SH` synthetic fixture 的通过仅证明该测试合同下的计算与事务，不能升级为三交易所费用验收。
