# TUI AI 服务商配置与排障

> 更新日期：2026-08-13

## 配置入口

- 普通用户在 TUI 的“我的 AI 服务商”页面管理个人服务商。
- 管理员在 TUI 的“系统 AI 服务商”页面管理系统服务商并执行连通性测试。
- 创建服务商时必须填写 API Key；更新服务商时 API Key 留空表示保留原密钥。

## 推荐排障顺序

1. 确认服务商处于启用状态，并检查默认模型是否由上游支持。
2. 管理员执行“测试系统服务商连通性”。
3. 核对 API Key、基础地址、API 模式和账户额度。
4. 查看最近 AI 调用日志，区分配置缺失、上游请求失败、超时和限流。

TUI 的布尔选项会按所选的 `true/false` 提交；列表中的掩码密钥不会回填到更新表单，避免把真实密钥覆盖为 `****`。
