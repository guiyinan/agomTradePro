# 社会面情绪源评估（S4）

> 评估日期：2026-07-31
>
> 范围：雪球、东方财富股吧、微博财经内容
>
> 默认决定：**当前均不接入生产 Pulse 或市场温度计；雪球直接抓取为“不接入”，股吧与微博为“暂缓”**

## 决策摘要

| 来源 | 合规/授权 | 稳定性与反爬 | 数据质量 | 结论 |
|---|---|---|---|---|
| 雪球 | 服务协议明确禁止网络爬虫、抓取/存储/索引，并禁止未经同意把平台内容提供给 AI 或用于 RAG | 登录态、非正常浏览识别和安全机制约束明确；绕过措施风险高 | 投资语义相关，但用户、标的和热门话题高度集中，转发/引用/营销内容会重复计数 | **不接入直接抓取**；只有雪球书面授权、许可数据/API 和用途条款齐备后另立计划 |
| 东方财富股吧 | 用户协议覆盖股吧；未见面向本场景、允许批量获取帖子正文的公开授权接口。未经事先书面许可不得以第三方工具干扰产品运行 | 页面/内部接口契约可变，账号与频控策略不构成稳定 SLA | 匿名散户浓度高，广告、喊单、重复帖、股票吧之间样本量差异大；平台也不保证用户信息真实、完整、准确或连续 | **暂缓**；优先采购/签约结构化舆情产品，禁止依赖未授权页面抓取 |
| 微博财经 | 有官方开放平台和付费 API/CLI 路线；访问范围、检索、留存和再处理仍须以具体合同/应用审核结果为准 | 官方 API 比页面抓取稳定；页面直接抓取、登录模拟和绕过限制不在候选方案内 | 覆盖广但财经纯度低，热搜/营销/水军、事件突发和转评链导致样本非独立 | **暂缓、条件候选**；只有官方 API 获批且完成 30 个交易日影子验证后再决定是否接入 |

## 合规依据与边界

1. 《个人信息保护法》第二十七条只允许在合理范围内处理个人自行公开或合法公开的个人信息；个人明确拒绝时不得处理，对个人权益有重大影响时仍需取得同意。社会帖子里的账号、昵称、头像、位置、关系链和发言历史不能因为“页面可见”就无限聚合。依据：[国家市场监督管理总局转载的《个人信息保护法》](https://www.samr.gov.cn/wljys/gzzd/art/2023/art_3ef1e889c1e644d4b65b5f5c7f432386.html)。
2. 2025 年修订、2025-10-15 施行的《反不正当竞争法》第十三条禁止以欺诈、避开或破坏技术管理措施等不正当方式获取、使用其他经营者合法持有的数据。依据：[国家知识产权局法律文本](https://www.cnipa.gov.cn/art/2026/5/20/art_104_206437.html)。
3. 雪球条款对爬虫、存储/索引、规避防护和未经同意把内容提供给 AI/RAG 均有明确禁止，因此 robots 可访问也不能替代授权。依据：[雪球服务协议](https://xueqiu.com/about/terms)。
4. 东方财富协议适用于股吧，明确不保证用户发布/转载信息的真实性、完整性、准确性，也不保证服务及时、连续；协议还限制未经许可通过第三方工具干扰产品运行。依据：[东方财富用户服务协议](https://about.eastmoney.com/home/protocol)。
5. 微博对平台、数据资料和内容权利作出明确约定；社会情绪接入应使用审核后的官方开放能力，而不是页面抓取。依据：[微博服务使用协议](https://www.weibo.com/signup/v5/protocol/)、[微博开放平台](https://open.weibo.com/cli/index)。

本文是工程接入评估，不替代正式法律意见。任何商业化、对外提供或用户画像用途都需要法务/隐私负责人复核。

## 数据质量验收条件

若未来 owner 选择推进微博或经授权的股吧/雪球数据，必须另立计划，并在进入任何决策指标前满足：

- 只保存情绪分析所需的最小字段；默认不采昵称、头像、个人主页、粉丝关系、位置和金融账户线索；源 ID 使用不可逆、可轮换的去标识化值。
- 原文只用于短期可追溯质检，设定明确保存期限与删除/拒绝处理通道；长期只留按“交易日 × 标的/市场”聚合结果和质量统计。
- 至少 30 个交易日影子运行，不参与 Pulse；每日发布去重率、疑似机器/营销占比、有效财经样本数、单一作者/单一平台集中度、模型置信度和缺失率。
- 转发、引用和跨平台搬运按内容指纹去重；同一作者短时批量发布限权；样本不足或集中度超阈值时 `must_not_use_for_decision=true`。
- 建立人工标注集，分开评估财经相关性、情绪方向和讽刺/反话；不得只用价格涨跌反推文本标签，避免标签泄漏。
- 任何站点登录模拟、验证码规避、IP/账号轮换、伪造请求头或调用未授权内部接口均为硬性禁止项。

## owner 决策门

在没有新的书面决定前，系统行为固定为：

- 雪球：不接入。
- 股吧：暂缓，不开发采集器。
- 微博：暂缓；可以另行调查官方 API 商务与权限，但本计划不实施。
- 社会面情绪不进入 S1-S3 的完成口径，也不影响当前 sentiment/Pulse 的 fail-closed 设计。

如果 owner 决定接入任一来源，必须单独批准数据授权、隐私影响评估、保存期限、退出/删除机制、质量阈值、成本和生产回滚方案，不得直接扩展本计划。
