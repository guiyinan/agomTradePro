# 报告二：ASH-11 对 DATA-18 的依赖瘦身

本报告提出拆分，不实施代码、不把 DATA-18 标为完成，也不修改发布验证策略。依据为登记表与 `docs/plans/production-recovery-and-regression-remediation-2026-09-24.md` 的 R1～R4、S1～S6 及既有安全门。

## 当前过宽的依赖

ASH-11 目前直接依赖 ASH-05、**ASH-06**、ASH-08、**整个 DATA-18**。ASH-06 已被 Owner 决定 deferred，若仍保留为完成前置，M3 将无法退出。DATA-18 的退出线覆盖发布恢复、Alpha、全市场容量、SDK/MCP、页面、任务诊断、数据库并发与完整预演，不都属于一个模拟账户的 M1/M2。

推荐把“完整 DATA-18 完成”改成“当前候选所用数据/账户/接口链路的有界验收完成”，把 ASH-06 从当前目标的 ASH-11 前置移除。**这只是依赖变更方案，尚未执行移除，也不降低被使用链路的安全标准。**

## 目标真正需要的数据

M1/M2 至少需要：账户归属、现金/持仓/冻结/可卖量、证券与交易所身份、合格交易日历/来源与 PIT、价格及其观测/可用时间、停牌/涨跌停/数量步长等本次声明支持的规则、真实成交/费用和幂等对账。财报、估值、Alpha 只在本次研究或目标生成确实使用时加入必需输入；未使用的能力明确未启用，不能假称已验。

## 按原阶段裁剪

| 原阶段 | M1～M3 必须保留的最小范围 | 可拆出后置的部分 |
| --- | --- | --- |
| R1.1 原任务/恢复 | 本目标实际依赖的刷新、导入任务有准确 outcome/计数/失败与恢复，不重复入账 | 与该账户/数据链无关的历史全任务追溯与全市场恢复 |
| R1.2 Publication | 实际读取的报价/价格，及用到的估值/财报，有原件、来源时点、不可变内容与有效 current 身份 | 未使用的数据集恢复；不以此免除已使用数据集的完整性 |
| R1.3 决策阻断 | 分清人工建议、数据不合格、权限缺失和自动执行阻断；保持全局门及真实 authority | 自动交易/全 R1～R8 Promotion 的消费者接线（EVID-03 已延期） |
| R1.4 Alpha | 只有目标生成实际启用 Alpha 时，保留该账户和目标日的依赖验收 | 全账户自动推理、全市场模型/自然计划恢复；不用 Alpha 时不列为 M1 前置 |
| R2.1/R2.2 | 计划/持仓/成交使用的 API/SDK/MCP 参数、分页、计数、错误、403/503 与未知写入一致 | 未使用信号/工具的全面迁移 |
| R3.1/R3.2/R3.3 | 一账户真实主流程、权限、GET 零业务写入、恢复、来源/费用/限制及时间清晰 | 无关 Workspace/Classic/全部研究入口扩展 |
| R4 | M1/M2 实际任务的 current/last-completed、outcome、计数与稳定错误码 | 全模块诊断面改造、通用性能整理 |
| S1/S2/S3 | 使用中的 provider 原件重放、源时间/PIT、账户隔离、过滤分页、失败写入、T+1/节假日/权限失效等反例 | 未启用市场/数据源/能力的契约扩展 |
| S4 | 冻结一个账户、持仓/目标/交易行数及其**实际触发的**数据规模，测延时、配额、查询、锁与恢复 | 只有路径确实不触发全市场任务时，才能后置全 universe 容量；UI 只显示一账户不等于后端有界 |
| S5 | 本目标变更的 component/PG 并发、跨模块消费者选测；必要 PG 检查不得以 SQLite skip 替代 | 无关工具迁移及覆盖治理 |
| S6 | 冻结发布候选，按现有正式策略执行适用预检、provider/Publication/规模变更的真实预演和隔离写验证 | 不要求每个开发 commit 单独做 S6；也不能删 required_reports 或把老 SHA 证据拼到新候选 |

Audit 的数据库别名、authority、generation/final-fence、publication/current-pointer/Outbox 的同事务证明，只要被本目标使用，就仍属必须。不能因“个人账户”或“只做展示”解除真实数据读取和发布的完整性门。

## 建议的登记改法（待 Owner 接受报告后实施）

- 保留 DATA-18 作为历史与剩余工作的父项，原证据不删。
- 另登记一个有界独立单元“当前手工辅助链路的数据与发布验收”，只承接上表必需范围；此处不预占新 ID，也不自动登记更多切片。其退出件必须有 exact-SHA、账户/资产/数据集/时段/规模清单，以及不触发其他范围的证明。
- ASH-11 依赖 ASH-05、ASH-08 及该有界单元；ASH-03/04/07 由前置链继承，ASH-06 不再为本轮前置。其余 DATA-18 残余工作单独后置，状态如实保持未完成。
- 17 项 TUX 待去重和非阻塞职责重构不成为 M1/M2 新前置；后者记录到 GOV-05 后续范围。

## M3 验收与停止线

冻结同一候选和一个 Owner 授权账户，实际完成 M1 计划、Owner 券商端手工成交后的显式导入、M2 对账和次交易日可卖量验证。生产只读复核可检查已产生的快照/成交/持仓，但不能凭 GET 宣称真实导入完成；写入验收须明确具体导入数据和授权范围。

如果该账户仍需完整全市场刷新、未通过的 Audit 全图或未提供的真实来源才能生成结果，它们是**实际阻塞依赖**，不能在纸面拆分掉。新依赖方案实施前应给出功能到源/查询/任务/发布路径的清单，并由独立复核确认边界。
