## 主讲口径与演示准备

开场建议：“一个人做投资，常常要同时承担数据助理、宏观研究员、标的研究员、量化研究员和风控复盘的工作。AgomTradePro 希望为你搭建一个人的投研队伍：让原生 AI 连接数据与工具，把机构化的研究分工和决策纪律带到个人。你掌握方向与关键决策，系统承接研究任务，今天就用一个具体问题展示这支队伍怎样工作。”

每页 `notes` 中包含演讲提示与主要事实依据，按 `N` 查看。投屏前关闭备注，避免把内部准备事项放到客户主画面。

现场演示建议安排 8–10 分钟，沿同一测试账户、候选标的和时间边界完成：

1. 在已发布的 `/tui/` 任务入口核对数据来源、观测时间与可用状态。
2. 打开候选信号，展示研究理由及明确的证伪条件。
3. 用隔离模拟账户预览风险检查，查看事先准备的审批记录。
4. 关联模拟持仓、交易与决策记录，回看依据和后续变化。

正式演示前，留存目标代码版本、环境、权限、数据截止时间、入口和业务记录 ID，并预演主路径及三个阻断场景：数据过期/发布缺失、证伪逻辑不完整、买入超账户限制。只演示已实际通过的环节；环境存在阻断时解释原因，改讲材料中的流程示意。本次材料编辑没有执行这些业务演示。

现有 Dashboard、Terminal 与 MCP 图片来自 README 留存截图，拍摄日期未标注，页内已标记为历史界面。Terminal 图中源观测日期为 `2026-03-23`，不代表截图拍摄日期或本次数据。功能全景图为关系示意。客户现场应使用目标环境的新截图或实时演示，记录角色、环境和源数据日期。

## 演示、阅读与截图呈现

默认演示模式使用 `1440×810` 的 16:9 固定画布，按实际内容区等比缩放。字号、卡片列数和图文关系由画布决定，浏览器缩放或窗口大小变化不会重新组织主讲版式。顶部“阅读模式”可切换为原尺寸的响应式文字阅读，长页在内容区滚动；触屏窄屏首次打开默认采用阅读模式，可手动切回演示模式。极小窗口的演示内容会整体缩小，阅读小字时请切换模式。

底栏高度按实际内容测量，为导航、操作提示和风险提示预留空间。以下提示来自 `deck.risk_notice`，在屏幕底部常驻，并在打印页面底部重复：

> 投资有风险，决策需谨慎。本系统提供投研辅助，不构成投资建议，不保证盈利。

主讲使用深色文字卡片、流程与对照表保持视觉连续；历史截图和浅底功能图集中在附录。图片使用统一展示框、标题条、来源说明与历史标记，`image.theme` 区分浅底截图和深色 Terminal；原始截图像素、颜色和数据不作修改，不把旧界面重新着色成当前产品。

## 文件说明

- `roadshow.json`：路演文案、页面结构和演讲备注，日常主要修改此文件。
- `template.html`：页面样式与播放功能模板，需要调整版式时修改。
- `build_release.py`：将 JSON、CSS、JavaScript 和本地图片全部内联到发布版 HTML。
- `agomtradepro-roadshow-inline-*.html`：生成的发布文件，请不要直接修改。
- `agomtradepro-client-roadshow-20261017.html`：本次客户版生成文件，请不要直接修改。

## 生成发布版

在仓库根目录运行：

```bash
python docs/roadshow/build_release.py
```

每次默认生成一个带时间戳的文件：

```text
docs/roadshow/agomtradepro-roadshow-inline-YYYYMMDD-HHMMSS.html
```

生成的 HTML 可以直接双击打开，无需启动 HTTP 服务。JSON 中引用的本地图片会以 Base64 内联；为保证离线可用，发布脚本不接受外部图片 URL。

也可以通过 `--output` 指定输出文件：

```bash
python docs/roadshow/build_release.py --output docs/roadshow/roadshow-demo.html
```

更新本次客户版固定入口时运行：

```bash
python docs/roadshow/build_release.py --output docs/roadshow/agomtradepro-client-roadshow-20261017.html
```

模板新增 `table` 页面类型，用于流程对照、阻断验证与客户问答；表头在 `headers`，等列数的行在 `rows`。播放器会检查列数，并以文本节点渲染内容。

## 播放操作

- 底部固定导航持续显示上一页、下一页、页码、操作提示及投资风险提示；窄屏保留翻页文字。
- 顶部“阅读模式 / 演示模式”：切换响应式滚动阅读与等比适配演示。
- `←` / `→` 或空格：翻页
- `O`：打开目录
- `N`：显示或隐藏演讲备注
- `F`：进入或退出全屏
- 底部“导出”：打印或导出 PDF
