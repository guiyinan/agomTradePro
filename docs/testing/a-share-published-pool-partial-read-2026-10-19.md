# ASH04 多证券股票池局部读取

本批衔接已交付的单标研究读取，处理现有股票池 API、SDK、MCP 和资产研究 TUI 的局部估值缺失。它是只读消费者切片，完整 ASH04 仍开放。

## 实现边界

只有已验证发布中的 `equity.valuation.fact` / `valuation_source_data_unavailable` 可以局部展示。请求代码必须绑定 master 实际解析出的 canonical asset、对应发布及成员范围；别名可以保留，缺少 master 时禁止用请求字符串猜身份。财务缺失、未知原因、零选中成员或发布身份/完整性错误仍阻断整个池。

既有服务端100只上限内，局部受限行保留原顺序、重复请求和完整分母。受限 PE/PB 为 null，其他已验证财务值可展示；逐行状态与池级 `outcome=partial`、`must_not_use_for_decision=true` 同时保留。均值只有覆盖完整请求分母才输出。全池阻断时逐资产受限数量未知则为 null，TUI 显示“未提供”。原始 None 时钟及逐指标来源时间保持，公开证据剔除内部原件定位信息。

完整 SDK payload 和默认治理 MCP 股票池入口保留池级 outcome、范围、计数及限制，客户端筛选不会重写原分母。旧 SDK 裸列表遇到受限或资格未知的 published 池时明确拒绝，提示使用 `get_stock_pool_payload()`；Sector 委托继承同一保护。旧客户端缺少完整股票池读取方法时，raw MCP 股票列表 fallback 也不再合成允许决策。显式 historical 保留兼容读取语义；单标详情继续采用保守的池级限制，未在本批重新设计逐行详情聚合。本批验收限于股票池列表，不代表其他旧推荐或财务兼容入口已全部重构。

现有 TUI 股票池摘要、明细及行业分布沿用既有 action。首屏显示可读状态、请求数量、受限数量与使用限制；正常零值保留，成功摘要使用中文业务描述。后端仍通过正式 Application 编排，Interface 没有新增 ORM，未新增模型、路由、页面或自动刷新。

原支持边界 RED、夹具修正及最终回归分别保留，不把不同源码的重叠包相加。原477项包为475通过、2失败；失败的历史 HTTP 夹具按[独立批次](a-share-model-history-fixtures-2026-10-19.md)修正，不能将它追认为477项全绿。

以 `cfcc2f374ed520fe532d0271d865765c0bff9541` 已提交父版本和本批冻结源码组成的隔离候选，最终 **80 passed**：38项后端、3条真实浏览器旅程、17项 MCP、21项传输和1项运行时清单契约。此前 SDK/行业/客户端/传输组合 **105 passed**，与最终80项有重叠，不相加。9个生产文件增量 mypy 与默认全库债务检查均为零错误；18个 Python 文件格式/lint通过，架构/audit、循环、88项当前数据合同、计划和治理检查通过。四份生成投影经官方工具重建并校验，六张最终摘要/明细截图已逐张查看。SQLite full 浏览器场景另按其403/404冻结输入通过，不能称为最终全部场景的跨库重跑。

独立行情夹具提交 `cfcc2f374` 的五条常规工作流现已实际成功，含 Python 3.11/3.13。这只证明该精确父版本及独立测试批，不是当前尚未提交股票池代码的 CI 结果。增量类型首次出现的三处 dynamic reader `no-any-return` 通过 JSON 边界的显式 `cast` 修正，未抬高债务基线；原始失败与修正后的零错误回执分别保留。

现有浏览器证据真实经过会话认证、metadata/ui_key、owner HTTP、Application 与渲染，仅注入持久池和已验证发布读取端口。它不证明真实 Provider、全市场发布或生产资格。隔离夹具中的辅助 governance queue 503 已单列记录，不能声称全部 HTTP 零错误；浏览器 JavaScript 错误、外部请求和请求失败按实际回执报告。
