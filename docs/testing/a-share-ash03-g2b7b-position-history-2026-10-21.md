# ASH-03：有成交回执的持仓写口保护（2026-10-21）

已有 V4 成交回执后，直接调用 Position 仓储改数量、可卖量、成本、资产类型或结算知识字段，以及删除或重建持仓，现以 `ORDER_FILL_HISTORY_RETAINED` 明确阻断。它防止无成交记录的资源校准改写成交后的持仓；普通结算 UoW 的合法 BUY/SELL 续写另批验收。

写入口先持有账户父锁，在持仓行锁之前按顺序读取相关预留、回执和成交标记。回执从预留及成交两侧账户/证券关系查找，防止损坏关系隐藏历史；即使回执缺失，V4 标量或绑定 JSON 标记仍能阻断。拒绝操作在财务 INSERT/UPDATE/DELETE 之前结束，测试同时比较账户、持仓、成交、预留和回执快照。报价及证伪更新、不同账户或不同证券、确无 V4 回执的普通 V3 兼容写入保留。
