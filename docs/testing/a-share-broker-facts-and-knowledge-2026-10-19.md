# ASH03：券商事实、余额声明与数量投影

本批修复真实成交导入与本地余额核对混在一起的问题：成交先作为事实保存，默认等待核对；只有用户明确选择“未包含”，且整份文件及本地余额仍与预览一致时，才进行数量投影。“已包含”只保存声明，不重复增减数量或创建交易镜像。

这是 ASH03 的有限业务批次。实施基线为 `aed7166fec03013a4558fd0243924a66c1c7ce69`，最终测试源码为 Source93，SHA-256 `d2c1456baae35c9672f8575df126c73c55671ac5627fd043a2acca7896f3a4c0`。之后只整理本说明、实施计划和验证原件，生产代码、测试及生成投影保持其已验证字节。新提交的远端 CI 独立核实，不沿用基线 SHA 的通过结果。

## 行为与边界

- `TransactionModel` 承载规范券商事实。稳定键、原始行、经济字段、费用已知标记、源成交时刻和本地记录时刻分别保留；重导不得改写原件或首次记录时间。
- 待核对、已包含、未包含三种选择贯通 HTTP、SDK、MCP 与既有 TUI 预览/确认操作。TUI 隐藏比较依据，确认时仍需选择同一 CSV；文件或余额变化返回明确冲突并保留已保存事实。
- 数量投影在所有者、组合和事实锁内执行，终态重试不重复记账。总数量、映射或明确资产分类不可信时保留事实并阻断；历史宽泛分类不默认猜成股票或基金。
- 数量投影不认证现金、当前估值或完整成本。未知值向账户、持仓、分享、绩效、净值任务与风险消费者传播 null/知识状态，不能把存储占位零或已知费用小计当成完整事实。
- 投影回滚后，回执使用重新锁定并实际更新的行。事实当前不可读取时发布明确恢复提示，不回填初始状态、不计入四项当前状态数量、不重建经济行。`facts_saved_count` 仍表示本请求先前成功写入的操作数。

完整参数、错误及迁移保护见[接口合同](../api/a-share-broker-trade-reconciliation.md)。普通模拟订单与事实镜像继续区分，真实成交数量投影不能用模拟新订单的可卖量权限拒绝既有成交事实。

## 失败与修正依据

保留实际 RED 原件：宽泛资产类别导致错误投影；数据库已阻断而旧 ORM 回执仍报 pending；两个 HTTP 入口各两种 CAS 冲突计数错误；事实删除后回退旧初始状态。Source85 的收据文件名虽含 green，实际退出码为 1，证据按真实结果记录。Source86 的数据库 blocker 已正确保存，错误发生在响应对象，不能解释为数据库未持久化。

独立复核最后发现的原始结果计数兜底已删除。异常读取、身份不匹配、未请求结果和 TUI 文案转换作为新增回归通过；这些后补边界不宣称曾在最终源码实际 RED。任务展示只移到已有通知模块以满足文件规模约束，未提高预算或新增平行框架。

[原始收据、日志、JUnit、源码哈希及浏览器证据索引](../../artifacts/a-share-usability/ash03-broker-facts/evidence.json)保存每次执行自己的输入身份。索引同时保留最初有待处理项的静态复核与之后确认修正的补充复核，不能把早期局部通过覆盖为最终整批通过。

## 剩余与恢复

完整 ASH03 的其余账本/结算退出项、实际券商持仓和现金对账、Owner M2/M3，以及 RC/S6、部署和实盘资格仍分别验收。real 账户现金没有被本批标为已核实；缺少依据时继续限制依赖该信息的计算，事实与独立已知数量仍可查看。

异常时先停止新导入/数量投影，保留事实、声明和知识状态，按可审计修正恢复。0068 与 0031/0032/0033 只在各自回退保护允许时删除字段；已有声明、未知现金、估值或成本知识不得直接丢弃。回退到忽略这些标记的旧代码不能证明安全恢复。本批没有执行生产迁移、main 合并、部署或下单。
