# TUI 任务模式使用说明

登录后打开 `/tui/`，默认看到三个任务入口。无需先配置全部 AI/MCP 服务或走完整专业流程。

- **研究标的**：输入当前数据支持的代码或唯一全名，主动提交。先看摘要、主要依据、反面因素和证伪条件，再展开证据。缺失、过期或禁止用于决策的材料会说明限制。
- **今日关注**：先看市场范围，按需选择获准的模拟账户查看对应队列。市场服务不可用时按页面提示恢复，不能把不可用状态当作市场正常。
- **检查组合**：选择自己有权查看的组合，查看已记录事实与缺口，按页继续。原币种、零值与缺失值分别保留；这些事实不自动构成投资或交易结论。

需要参数、完整工作区或详细管理时切到**专业模式**，也可从任务结果进入对应专业详情再返回。模式切换保留当前页面和输入，不提交动作；诊断工具使用独立服务端权限。

键盘为可选路径：F6 提交当前可见的主任务；表单收起时先用 F9 重新打开。F6 保留已输入内容，选中表格行不会自动覆盖表单；需要带入行数据时使用明确的填入操作。

这份说明对应本地仓库升级。是否能完成真实研究，仍取决于已授权的数据与能力；五人上手试用和生产发布另行验收。
