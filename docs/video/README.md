# AgomTradePro 宣传视频

当前主版本为约 2 分半的竖屏工作流版：围绕“个人可用，目标是机构级研究与风控底座”，展示数据校验、研究与证伪、前置风控、验证与复盘四条工作流，以及 AI 的辅助作用和人工确认边界。

Git 保存文案、制作脚本、字幕和封面；视频与音频文件由本目录 `.gitignore` 忽略，只保留在本机。下方成片与配音链接指向本地生成产物，新克隆仓库需按制作说明生成。
