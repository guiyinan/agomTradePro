## 工具与复现

本次使用 Python 3.13.5、Pillow 11.1.0、NumPy 2.3.2、`edge-tts` 7.3.1、`imageio-ffmpeg` 0.7.0（FFmpeg 7.1）。中文字体来自 Windows：`C:\Windows\Fonts\msyh.ttc` 和 `msyhbd.ttc`。Edge TTS 与 FFmpeg Python 包仅安装到临时目录，没有修改项目虚拟环境或依赖清单。

在仓库根目录以 PowerShell 执行：

```powershell
New-Item -ItemType Directory -Force -Path '.\.tmp\agom-brand-video-20261028\tools\site-packages' | Out-Null
& '.\agomtradepro\Scripts\python.exe' -m pip install --disable-pip-version-check --no-warn-script-location --target '.\.tmp\agom-brand-video-20261028\tools\site-packages' 'edge-tts==7.3.1' 'imageio-ffmpeg==0.7.0'
$env:PYTHONPATH = (Resolve-Path '.\.tmp\agom-brand-video-20261028\tools\site-packages').Path
& '.\agomtradepro\Scripts\python.exe' '.\docs\video\agomtradepro-promo-20261028\render_agomtradepro_promo.py' --preview --time 31
& '.\agomtradepro\Scripts\python.exe' '.\docs\video\agomtradepro-promo-20261028\render_agomtradepro_promo.py' --prepare-audio
& '.\agomtradepro\Scripts\python.exe' '.\docs\video\agomtradepro-promo-20261028\render_agomtradepro_promo.py' --render
```

`--preview` 只写临时预览图；`--prepare-audio` 生成按镜头排布的旁白与 SRT；`--render` 生成全部交付物。脚本会复用 `.tmp/agom-brand-video-20261028/tts/voice-*.mp3` 中已有的分段语音。修改口播或语速后，先删除这些分段文件再执行 `--prepare-audio`。

音频处理参数：旁白 `loudnorm I=-16 / TP=-2 dBTP`；原创配乐目标 `-28 LUFS / -9 dBTP`；`amix normalize=0`，随后限峰并将总线归一至 `I=-16 / TP=-1.5 dBTP`。编码时使用 4 个线程。
