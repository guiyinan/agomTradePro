## 配音正文

这是我正在做的 AgomTradePro。目标，是让个人也能拥有机构级的研究与风控底座。

个人可以自行部署。接下来，沿着一个研究想法，走过数据、研究、风控和复盘四条工作流。

第一步，把研究建立在数据上。行情、宏观指标和财务材料汇集后，核对来源、观测时间和可用范围。

数据过期、缺失或者不可靠，就保留原因、限制用途。每一个判断，先回答依据从哪里来、当时是否可用。

第二条，是研究工作流。先看增长、通胀和政策环境，再深入行业、股票或基金，把环境判断与标的研究连起来。

形成投资信号时，记录看好的理由，也写清什么条件出现，就要推翻判断。研究结论有依据，也有失效边界。

第三条，是决策前的风控工作流。根据账户和策略，检查总仓位、单一标的集中度、现金底线，以及风险限制。

拟议操作触碰约束，就拦截并说明原因；满足检查要求，再进入相应的审批流程。需要人工确认的步骤，保留在人的手里。

第四条，是验证与复盘工作流。先用历史回测检查想法，再用模拟交易观察过程，把持仓变化和决策记录留下来。

复盘时，回看当时用了什么证据、做了什么判断、触发了哪些限制。让下一次研究，可以沿着记录追溯和修正。

AI 可以参与这些工作流：查数据、整理分析、提出方案。它的能力受权限和确认流程约束，重要操作留下审计记录。

项目开源，持续开发中。你可以配置自己的数据源和 AI 服务，从日常研究开始，逐步搭建自己的方法。

| 2 | 09–20 秒 | 一条研究想法进入个人工作台；数据、研究、风控、复盘四条线 | 视线随一张“研究想法”记录前行；每条线亮起，展示将要交付的证据、信号、检查结果和复盘记录。 |
| 3 | 20–32 秒 | 工作流一：行情 / 宏观 / 财务材料 → 来源 → 观测时间 → 可用范围 | 三路来源逐条进入资料清单；镜头放大一份证据，展开字段。输出“可核对的研究材料”，不虚构市场数据。 |

| 5 | 44–57 秒 | 工作流二：增长 / 通胀 / 政策 → 行业 → 股票或基金 | 宏观象限、政策脉络、标的资料依次进入同一研究案卷；在标的研究中展开“行业观察 / 估值研究 / 因子分析”三个支撑入口，从环境视图推进到标的视图。 |

## 画面制作要求

- 每个章节至少经历输入、检查或加工、输出三个视觉状态；用连线、视线推进、局部放大、文件展开和分支结果体现因果。
- 风控章节的 18%、4%、22%、20%、1%、19% 是本片专用的说明性例子，整段标注“示例账户 / 示例配置”；不冒充真实账户、系统默认策略或建议仓位。这组数字只用来解释配置上限如何约束拟议操作。
- 采用纵向流程、证据案卷、检查面板、审批分支和时间轴等不同构图。避免连续重复三张横排卡片，也不通过密集小字填满画面。
- 阿狗是系统身份标识：片头与片尾作为主视觉，功能段作为工作台标记。主体画面保持专业、克制。
- 深色工作台与浅色证据纸页交替使用，金色标记研究线索，薄荷绿标记正在推进的流程。行情蜡烛图遵循红涨绿跌；风险告警单独用状态文字解释。
- 全片功能画面使用原创流程示意，不伪装成生产实录或某账户的真实交易。片头与片尾清楚保留“持续开发中”。
- 中文信息分层：主标题、当前步骤、证据字段、短句字幕。旁白字幕按短句切换，避免一屏同时出现整段口播。
- 配音使用 `zh-CN-YunyangNeural`，语速以沉稳清楚为准，背景音乐低于人声；超过预算时可在用户允许的 2–3 分钟内调整停留，不硬拉伸或裁断语音。
