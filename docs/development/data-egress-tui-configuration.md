# 数据出网配置操作说明

入口：系统治理 → 数据出口配置，或 `/tui/?screen=data-center.egress-config`。

本页供管理员配置数据中台的网络出口。业务模块继续向数据中台取数，路由按数据源、数据集、目标域名和执行节点区域匹配。

也可通过默认 MCP 入口管理同一份配置，见 [MCP 操作说明](data-egress-mcp-configuration.md)。

## 使用顺序

1. 在“数据出口配置”登记出口。填写代理主机、端口、区域、连接方式和并发上限；需要认证时填写账号、密码。首次保持停用。
2. 从可用数据源清单选择“新增规则”，数据源编号会回填。为实际数据源新增规则，填写数据集、目标域名、执行节点区域和优先级。选择直连、固定出口或直连失败后使用备用出口。首次保持停用。
3. 测试指定出口时提供具体数据集、区域和完整目标地址；测试要求目标符合已登记规则，停用的规则也可以作为测试许可。通配规则不能代替具体测试参数。
4. 核实结果后先启用出口，再启用规则。启用规则前，对应出口必须已经启用。
5. 使用预览检查命中规则和预期路径；使用连接诊断检查实际请求尝试及错误。预览本身不访问行情服务。

股票历史数据集为 `equity.price.bar`。执行节点区域必须与应用部署的区域配置一致，不能把出口的境内区域直接当作境外执行节点区域。

## 修改与停用

从列表选择记录进入编辑，核对回填值后保存。密码不回显；留空保留原认证信息。需要移除认证时使用明确的清除操作。

需要撤销路由时先停用规则。固定出口规则仍启用而出口被停用时，请求会阻断；不会自动绕过规则直连。直连失败后的备用出口只有选择相应策略时才会使用。

## FRP 与验收边界

页面登记的是可供应用访问的代理。部署模板中的代理主机通常为 `frpc_egress_visitor`、端口为 `18080`；填写前应核对自己的部署。

frpc/frps 的启动、STCP 鉴权和容器网络由 [FRP 部署说明](../../deploy/frp/README.md) 管理。页面保存出口不代表隧道已经启动。真实境内出口 IP、行情结果以及断链恢复必须在实际部署环境验证；本地配置和表单验证不能替代网络验收。
